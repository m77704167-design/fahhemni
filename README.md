# فهمني — Fahhemni v2

نسخة Vercel/GitHub جاهزة: رفع صورة، OCR عربي/فرنسي/إنجليزي، إدخال يدوي، حل مسائل رياضية بسيطة، شرح خطوة بخطوة، سجل محلي، RTL، وتكامل اختياري مع Gemini عبر `GEMINI_API_KEY`.

## النشر
1. ارفع الملفات إلى مستودع GitHub.
2. استورد المستودع في Vercel.
3. إذا أردت التحليل بالذكاء الاصطناعي أضف `GEMINI_API_KEY` في Environment Variables.

لا يحتاج المستخدم إلى Termux لتشغيل الموقع المنشور.
