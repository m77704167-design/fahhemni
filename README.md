# فهمّني — Fahhemni

نسخة أولية من موقع "صوّر الوثيقة، ونخبرك ماذا تفعل".

## تشغيل على Termux

تحتاج Node.js حديثًا (Vite 8 يتطلب Node.js 20.19+ أو 22.12+).

```bash
cd fahhemni
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر لك، أو من الهاتف افتح:
`http://127.0.0.1:5173`

## بناء نسخة الإنتاج

```bash
npm run build
```

سيتم إنشاء مجلد `dist`.

## مهم

هذه النسخة **واجهة MVP جاهزة للتجربة**. زر التحليل يستخدم نتيجة تجريبية محلية حتى لا نضع مفاتيح API داخل المتصفح.

المرحلة التالية لربط التحليل الحقيقي:
1. رفع الملف إلى خادم آمن.
2. OCR للغة العربية والفرنسية.
3. تحليل النص بواسطة نموذج ذكاء اصطناعي.
4. إعادة JSON منظم: نوع الوثيقة، الملخص، الإجراء، الموعد، المبلغ، الوثائق المطلوبة.
5. إضافة حسابات المستخدمين والتخزين والتذكيرات.
